Browser Control · local demonstration

Automate a tab. Pause for the person.

A local agent fills this sample form through Playwright, then Browser Control displays its real human-handoff prompt.

Sample webpage

Commands used for this demonstration

await page.getByLabel("Task name")
  .fill("Documentation demo")

await page.getByLabel("Theme")
  .selectOption("dark")

await handoff(
  "Review the sample form. " +
  "Click Continue when you are ready."
)

This is a synthetic local webpage, not an extension settings screen. The floating handoff prompt is provided by the installed Browser Control extension. No account or payment is involved.
